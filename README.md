# CenterGravity

This tool allows to calculate the center of gravity of an element or of the set of elements; essential data if we want to carry out a lifting study.

**Center Gravity 2.0.0 — What's new**

**Now supports Revit 2024, 2025, 2026 and 2027.** One installer covers every release.

**New dockable panel.** Docks like Properties, updates live as you select, follows the Revit light/dark theme, and lists each selected element with its volume and mass.

**Centre of gravity by mass.** Weight the result by volume or by material mass, with an optional default density for materials that don't carry one. The total mass is shown next to the volume.

**Works on assemblies and model groups.** Select the container and it expands to its members automatically — no exploding or regrouping.

**A marker you can schedule and tag.** The centre-of-gravity point now carries shared parameters (coordinates, volume, weight, lift name, reference, date). One click builds a Center of Gravity schedule.

**Reference point.** Report coordinates from the internal origin, the project base point or the survey point.

**Preliminary rigging checks.** Pick 2 or 4 lift points to get the load share per leg, a centre-of-gravity-inside-the-lift-points check and an uplift warning; add a hook height for sling angle, sling tension and tilt. A preliminary aid — not a certified lift plan.

**Export.** Copy the coordinates or export the elements, totals and rigging to CSV.

**Also:** the marker is now placed only on demand (Place marker), selection detection is more reliable and language‑independent, and the tool computes from the current selection as soon as it opens. Fixes: no more empty result on selections without solid geometry, corrected weighting for multi‑solid elements, unit‑aware values.

Once the plugin is installed, the **JDS** tab will appear in Revit which contains this and all the author's solutions.
